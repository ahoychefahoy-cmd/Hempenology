# Hempenology

Independent Hempenology website. Plain static HTML, CSS and JavaScript.

## Cloudflare Pages settings
- Production branch: `main`
- Framework preset: `None`
- Build command: leave blank
- Build output directory: `/` (or `.` if required)
- Entry point: `index.html`

No build process is required. The website uses the existing Hempenology banner image hosted on Shopify's CDN.
