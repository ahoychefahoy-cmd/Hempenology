# Hempenology website V2

A responsive static website for Hempenology.

## Files
- `index.html` - page structure and content
- `styles.css` - responsive visual design
- `script.js` - mobile navigation and current year

## Deploy with Cloudflare Pages
Use the GitHub repository connected to your Cloudflare Pages project.
- Framework preset: None
- Build command: leave blank
- Build output directory: `.`
- Production branch: `main`

Upload/replace the three website files in the repository root and commit the changes. Cloudflare Pages should automatically deploy the new commit.

## Notes
- The existing Hempenology Shopify banner artwork is reused as the hero background.
- Destination card photographs are loaded from Unsplash.
- Contact details are intentionally marked as coming soon until the preferred public email address is confirmed.
- Product listings, live shop checkout and journal articles are not yet connected.
